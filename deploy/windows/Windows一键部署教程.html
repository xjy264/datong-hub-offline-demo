大同示意图 Windows 一键部署教程

版本 2026.07.22.1；Windows 11 实机通过、Server 2012 R2 兼容候选。最低要求：Windows 6.3 x64、PowerShell 4.0。

现场人员只做三件事：解压、双击、允许管理员权限。

1解压

把完整离线 ZIP 解压到 C:\DatongMap。确认能看到：

C:\DatongMap\开始部署.cmd
C:\DatongMap\app
C:\DatongMap\runtime
C:\DatongMap\scripts

2双击

双击 开始部署.cmd。Windows 询问是否允许修改设备时点击“是”。

保持黑色窗口打开。五个阶段会自动执行，不需要填写 MySQL 账号或密码。

3等待五个阶段

  1. 服务器和离线组件检查
  2. 目录、配置和 HTTPS 证书
  3. 项目独立 MySQL
  4. MinIO、后端服务、防火墙和备份
  5. 服务、健康接口和首页验收

已有 MySQL 保持原状；项目 MySQL 自动选择 3306 或 3311。

绿色 PASS：部署成功

浏览器结果页显示 PASS 后，把 client 目录和 客户端证书安装.cmd 复制到客户端电脑。访问地址为 https://服务器IP:8012。

红色 STOP：把材料发给技术人员

结果页会显示失败阶段、失败组件、错误编号和原因。点击“复制反馈信息”，再发送页面列出的 DatongMap-Diagnostics-时间.zip。

现场人员此时不要删除目录、数据库或重新改端口。

常用材料位置

  • C:\DatongMap\reports\deployment-status.html
  • C:\DatongMap\reports\deployment.log
  • C:\DatongMap\DatongMap-Diagnostics-时间.zip

诊断材料会自动过滤密码和密钥。
